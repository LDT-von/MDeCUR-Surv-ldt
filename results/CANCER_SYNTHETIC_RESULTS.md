# 癌症生存模型的合成检查（无患者数据）

模型模拟连续时间事件与独立随机右删失，每次 360 人，180/60/120 分别训练/验证/留出。WSI 和 RNA 均为人工生成特征，不是癌症数据。时间 2 的风险用于计算 Harrell C；NLL 是连续时间密度的平均负对数似然，取值受时间单位影响，仅可比较同一模拟设定下的模型。分组损失、权重和训练曲线在 JSON 中。以下为种子均值，样本小、无置信区间。

第一轮 `cancer_synthetic_v1.json`：种子 11/23/37，共同约束 0.001、稳定性强度 2。稳定性和等权 DeCUR 的 NLL 均值四舍五入到小数点后四位完全相同；模拟高噪声组的权重下降，但预测收益无法与普通约束区分。

第二轮 `cancer_synthetic_v2.json`：受第一轮结果启发提高共同约束到 0.02、权重强度 8，使用新种子 41/53/67。高噪声组确实获得较低权重，但稳定性、等权和随机权重仍非常接近。该轮为探索性修改。

第三轮 `cancer_synthetic_v3.json`：共同约束提高到 0.2、强度 8，使用新种子 71/83/97。互补信号中，普通融合 NLL 1.017，等权 DeCUR 1.069，稳定性加权 1.069；更强约束可能损害有用的模态差异，权重未解决这一问题。同一模拟场景各臂使用相同患者及训练/验证/测试划分；种子均值不构成统计显著性结论。

第四轮 `cancer_synthetic_v4.json`：固定第二轮配置（0.02、强度 8），用新种子 101/103/107/109/113/127；此固定是在读取这六次结果前执行，但不构成完整预注册的临床研究。

| 模拟情形 | 病理 NLL | RNA NLL | 普通融合 NLL | 等权 DeCUR NLL | 随机权重 NLL | 稳定性 NLL |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 共同信号 | 1.154 | 1.101 | 1.089 | 1.091 | 1.091 | 1.091 |
| 互补信号 | 1.154 | 1.103 | 1.017 | 1.016 | 1.016 | 1.016 |
| 部分病理视图噪声 | 1.188 | 1.103 | 1.044 | 1.036 | 1.036 | 1.036 |
| 不稳定视图有预后信号 | 1.232 | 1.156 | 1.138 | 1.143 | 1.143 | 1.144 |

第四轮稳定性相对等权 DeCUR 的 NLL 平均差分别为 +0.00003、-0.00004、+0.00012、+0.00042（负数为更好）；对应胜出的种子数为 2/6、4/6、3/6、1/6。高噪声组的权重较低，并不证明在复杂真实肿瘤中这些样本不可靠；若不稳定反映的是肿瘤异质性而非噪声，降权可能丢失重要信息。现阶段结论是：普通多模态模型可在这些模拟条件下学习一定信号，但**稳定性加权没有显示出可归因的优势**；真实癌症表现未知。

从项目目录运行以下命令时请更换输出名，程序不会覆盖已有结果：

```powershell
python cancer_synthetic.py --output results/repeat_cancer_v1.json --seeds 11 23 37
python cancer_synthetic.py --output results/repeat_cancer_v2.json --seeds 41 53 67 --lambda-common .02 --strength 8
python cancer_synthetic.py --output results/repeat_cancer_v3.json --seeds 71 83 97 --lambda-common .2 --strength 8
python cancer_synthetic.py --output results/repeat_cancer_v4.json --seeds 101 103 107 109 113 127 --lambda-common .02 --strength 8
```
